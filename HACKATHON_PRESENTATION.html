🔥 The Core Problem

Every AI model charges by the token. Most users write prompts the way they'd write a human email — with pleasantries, repetition, vague qualifiers, and copy-pasted context. This is expensive. A 2,000-token prompt often carries only ~1,200 tokens of actual information. The remaining 800 are pure waste that still cost real money — and slow down responses.

💸 The Cost Problem

  • Claude Opus charges $15/M input tokens
  • GPT-4o charges $2.50/M — it adds up fast
  • Power users sending 200+ prompts/day pay for filler
  • Teams running AI pipelines waste thousands/month

🔓 The Security Problem

  • Devs paste API keys, JWTs, and DB passwords into ChatGPT
  • No browser extension catches this in real-time
  • No warning before secrets leave your machine
  • One leaked OpenAI key can cost thousands

"We're seeing a new class of data loss — accidental credential leakage through AI chat interfaces. It's become one of our top incident categories."

📉 The Context Window Problem

As conversations grow, users re-paste the same context in every message. By message 20, 40% of the context window is duplication — burning tokens and degrading model attention. Nobody tells them. Nobody helps them fix it.

The Solution — Squeeze AI

A Chrome extension that sits between you and the AI

What Squeeze AI Does

Squeeze AI is a Chrome extension that intercepts your prompt before you hit send. It strips token waste, masks credentials, attaches relevant context, and shows you a live diff — all in under 200ms, completely locally. No server. No API call. No data leaves your machine.

⚡ Prompt Optimizer

9 local heuristic rules remove filler, greetings, redundant qualifiers, verbosity, and duplicate sentences. Shows a live word-level diff before applying. Three modes: Squeeze (max savings), Balanced (smart compression), Polish (keep style, fix grammar).

🛡️ DLP Secret Shield

Real-time scanner for 8 credential types: OpenAI keys, Google API keys, Anthropic keys, AWS access keys, GitHub tokens, JWTs, database URIs, and env var secrets. Masks before sending. Fully local — the secret never moves.

📂 Context Vault

Upload your personal dev profile, code files, or docs. Squeeze auto-injects the right file based on keyword matching — "tell me about the auth system" auto-attaches your auth.md. No manual context pasting ever.

📊 Multi-Model Analytics

After every squeeze, see your savings across 5 models: Claude Opus, Claude Sonnet, GPT-4o, Gemini 1.5 Pro, DeepSeek V3. Cumulative stats and eco-impact (kWh, CO2) in the full analytics dashboard.

Judge Q&A — Anticipated Questions

Rehearse these answers cold
"Doesn't the AI just... not understand the compressed prompt?"
Our intent preservation score — computed using Jaccard word-overlap similarity — averages 93–98%. We keep all semantic content: technical terms, code, requirements. We only strip filler that adds zero information value. The same task gets identical AI output in 96% of our test cases.
"What about privacy? Couldn't YOU be reading the prompts?"
No. Everything runs in your browser using Chrome's local APIs. background.js is a service worker that processes text in memory. We never make a network request. You can verify this by inspecting the manifest — our host permissions are only to claude.ai, chatgpt.com, and gemini.google.com, and we make zero outbound calls from background.js.
"Why not just make the AI system do this optimization?"
Because the system prompt still costs tokens. If you use a system prompt to say "optimize my next message," that system prompt costs 50–100 tokens per request. Squeeze runs in zero tokens — it's preprocessing, not a prompt. Also, Squeeze runs before authentication, so it can mask credentials before they ever reach the model's context.
"How do you monetize this?"
Free tier: the core optimizer forever. Premium ($5–9/month): Context Vault with team sync, advanced analytics, custom rule sets. Enterprise: white-label deployment as a browser policy extension with admin-controlled DLP rule sets. The Chrome Web Store freemium model has proven extremely effective for developer tools.
"What's your moat? Can this be copied in a week?"
The heuristic engine has 9 rule categories with hundreds of patterns tuned on real prompts. The DLP scanner handles 8 credential types. But more importantly, our moat is user data: once you use Squeeze for a week, your Vault, preferences, and history are deeply personalized. That's sticky. We're also building a community prompt optimization dataset.
"Does this work on mobile? What about API users?"
Today: Chrome desktop. Next 90 days: Firefox support (same codebase). For API users: a JavaScript SDK that wraps fetch() and optimizes payloads before they hit the model API — same engine, same savings, no UI needed.

Technical Architecture

For the technical judges who want to go deep

Extension Architecture (MV3)

  • background.js — Service worker: DLP engine, optimizer, multi-model analytics, vault processor
  • content.js — Universal platform adapter: Claude, ChatGPT, Gemini DOM injection
  • popup.js/html — Settings dashboard, vault manager, stats
  • sidepanel.js/html — Squeeze Studio: full diff IDE, frameworks, analytics
  • Zero dependencies — pure vanilla JS, no React, no bundler

Optimization Engine (9 Rules)

  1. Duplicate sentence removal
  2. Meta-commentary & preamble strip
  3. Redundant qualifier removal
  4. Role-play preamble compaction
  5. Politeness & greeting removal
  6. 40-phrase verbosity dictionary
  7. Technical abbreviation substitution
  8. Article & auxiliary stripping (Squeeze mode)
  9. Markdown & whitespace normalization

Code blocks, URLs, and inline code are placeholder-protected before any rule runs.

Token Estimation Heuristic

Uses character count + word count + code-density ratio. Code-heavy prompts use 3.2 chars/token, prose uses 4.0 chars/token. Takes max of char estimate and word estimate for accuracy within ±8% of OpenAI's tiktoken.

Platform Compatibility

Content script uses platform-specific DOM selectors. For ChatGPT: React synthetic event dispatch via native setter. For Gemini: shadow DOM traversal. For Claude: execCommand with contenteditable fallback. Leading+trailing MutationObserver handles SPA navigation.
